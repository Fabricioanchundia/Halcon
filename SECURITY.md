# Política de seguridad

Halcón es un proyecto de portafolio con datos 100 % simulados: no contiene datos reales de
clientes ni de tarjetas.

Si encuentras una vulnerabilidad, **no abras un issue público**. Usa **Security → Report a
vulnerability** en este repositorio (aviso privado de GitHub). Respondo en un máximo de 7 días.

El análisis de amenazas está en [docs/threat-model.md](docs/threat-model.md).
